# Lixeira-Automatica-com-arduino
Sistema criado por mim para uma lixeira automática com sensor feito no Arduino Uno

Itens Necessarios:
•	Arduino Uno; 
•	Sensor ultrassônico HC-SR04; 
•	Servo motor SG90; 
•	Protoboard; 
•	Fios jumper; 
•	Estrutura física da lixeira;
• Cola quente e Fita;


Link do projeto no Thinkercad -> https://www.tinkercad.com/things/d8ijNhSOEgd-projeto-lixeira-automatica-iot03
